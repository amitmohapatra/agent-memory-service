**What was learned.**
- Push matches the whole-conversation ceiling: the misses are reading (lists one short, "I
  don't know" where "Likely" was supported, facts only in images), not memory.
- On demand trailed because a search returned at most 20 lines and named no speaker
  (replayed: every piece of a many-part answer found for 49% vs push 81%; ~11 wrong-person
  errors). Both are fixed on main; the full arms are not run yet.
- Noise: ~100 memories per question where 1-2 are needed. It does not lower accuracy at this
  size (push = ceiling) but costs ~6,100 tokens. No-model trims (smaller budget, fewer
  memories, top-N plus linked turns, relevance floor) all lost 0.5-5 points of answers
  (`scratchpad` sweeps, free); only a model reading the content can cut it.
- The knowledge graph is too noisy to show ("Shared", "Thanks", "Yeah" as entities, from word
  patterns, in both stores; "Caroline" not merged with `user:caroline`).

## Goal the owner set

- The context an agent gets is **precise**: only what bears on the question, each statement
  once, the same sections in the same order every time, everything dated.
- **The agent fetches the rest on demand** (memory tools), like Claude Code / Letta.
- **No hardcoded language rules** deciding what a person said: where a model is allowed it
  reads; what the app or the source says (role, origin, kind) decides the rest.
- Memory is the single durable source of truth, multi-tenant, high throughput.

## The context, as agreed (built and on main)

Profile (identity + rules/preferences that apply, dated) -> Conversation summary (written by
the LLM, long chats only; none without a model) -> Learned skills (steps, track record, task
match) -> Tools (only known values, missing arguments, next step) -> Recent conversation (day
and time per message, tool steps with their age) -> Memories (related, each once, dated; most
related first, then time order) -> Documents -> Memory status (one sentence, when not
complete). On-demand agents (`recall: false`) get everything but Memories and Documents and
fetch the rest with the memory tools. No Facts lines (a search asks for facts by kind), no
People section, nothing said twice. Do not redesign; change only when a measurement says so.
